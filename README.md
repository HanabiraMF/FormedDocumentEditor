# 文档制作工具 · Doc Builder

一个基于浏览器的可视化文档编辑器。通过拖拽组件即可搭建内容，支持多页面、主题切换、导出网页 / PDF / Markdown，所有数据保存在浏览器本地。

单个 HTML 文件，无构建流程，双击即可运行。

## 特性总览

- 拖拽式编辑：左侧组件面板拖入画布，或点击插入到选中块内部
- 多页面：支持父子层级的页面树，拖动页面即可调整顺序或建立层级
- 21 套主题预设：覆盖玻璃拟态、Material、扁平、新拟态、粗野、终端、杂志、极简、Fluent、黏土、便当盒、极光、赛博朋克、蒸汽波、北欧、Carbon、Dracula、Linear 等风格
- 浅色 / 深色 / 跟随系统三种显示模式，编辑器与导出网页同步变色
- 自定义 CSS：可覆盖主题变量或撰写选择器，作用于预览与导出的文档
- 触发器系统：为按钮绑定动作序列，支持嵌套的循环与条件判断
- 四种导出：完整网页、多页面 ZIP、PDF（打印）、Markdown，另有 JSON 备份与 HTML 片段
- 本地自动保存：编辑内容写入 `localStorage`，刷新后可恢复
- 撤销 / 重做、多选、块级右键菜单、快捷键

## 快速开始

1. 将 HTML 文件保存到本地，双击用现代浏览器打开
2. 首次启动会加载 CDN 依赖（Font Awesome、highlight.js、KaTeX、marked、JSZip）
3. 依赖加载完成后，选择模板或点击「以空白开始」
4. 从左侧拖入组件开始编辑

无需服务器，也无需安装任何依赖。建议使用 Chrome、Edge 或 Firefox 的最新版本。

## 界面结构

应用分为三个可拖拽调整宽度的区域：

| 区域 | 内容 |
|------|------|
| 顶栏 | 文件菜单、撤销 / 重做、模式切换、主题、复制 HTML、全屏、帮助、预览 |
| 左侧面板 | 页面树、组件搜索、提示框主题、常用组件列表 |
| 中间画布 | 当前页面的编辑区，双击空白可快速插入文本块 |
| 右侧面板 | 选中块或页面后的属性设置 |

左右面板的宽度可通过拖拽边缘调整，双击分隔条恢复默认。

## 组件列表

### 基础内容

- 标题：H1 到 H4 四级
- 正文段落
- 列表：有序或无序
- 引用块
- 分割线
- 竖分割线：用于行内布局中产生垂直分隔

### 富文本与代码

- 代码块：语法高亮，HTML / XML 时出现「运行」按钮，可在新窗口预览
- 数学公式：LaTeX 语法，编辑框下方实时预览
- Markdown：实时渲染，点工具条的「运行」在新标签页查看

### 媒体

- 图片：点击选择本地文件，或直接拖入替换
- 视频、音频：本地文件或外链
- 内嵌网页：通过 iframe 嵌入外部页面

### 结构与导航

- 表格：可增删行列、设置表头、调整边框粗细与颜色
- 行内布局、列布局：实现横向或纵向排列
- 树结构：多级节点，可动态添加子节点
- 目录：导出时自动根据页面标题生成
- 页面链接：跳转到本文档的指定页面
- 页面嵌入：在当前页面中展开另一页面的内容
- 外部链接：指向外部网址
- 触发器：按钮，点击时执行动作序列

### 提示框

提供 12 种配色主题：笔记、提示、信息、警告、危险、成功、问题、失败、缺陷、示例、摘要、引用。支持自定义颜色、边框粗细，以及是否可折叠。

## 主题与外观

点击顶栏的「主题」按钮打开外观面板，包含三个选项卡：

### 风格预设

每套预设包含结构样式（圆角、阴影、边框、字体、间距）与配色变量（浅色与深色两套）。点击卡片即可切换，编辑器画布与导出文档同步换肤。

### 自定义 CSS

在文本框中撰写 CSS，会追加到主题之后，仅作用于文档内容，不影响编辑器界面。推荐通过覆盖 `--doc-*` 变量换色，或使用选择器对具体组件做深度定制。

### CSS 变量文档

列出所有可覆盖的 CSS 变量、可用选择器以及常用示例，可供快速查阅。

显示模式独立于主题，通过「浅色 / 深色 / 跟随系统」三个按钮控制。选择「跟随系统」时，会读取操作系统的 `prefers-color-scheme` 自动切换。

## 触发器

触发器是一类可点击的按钮，点击后按顺序执行配置的动作。每个动作可设置目标块、参数以及嵌套的子动作。

支持的动作类型：

- 全屏显示目标
- 播放动画（淡入、滑入、缩放、脉冲、抖动等 13 种）
- 改变目标文字
- 显示 / 隐藏目标
- 移动目标位置（按像素偏移，可设置时长）
- 改变目标颜色（文字色 / 背景色 / 边框色）
- 滚动到目标
- 打开链接
- 等待指定时长
- 循环执行（可指定次数，循环体内可继续嵌套）
- 条件判断（根据目标是否可见、文字内容或是否包含某个类名走不同分支）

动作列表在右侧属性面板中以树形展示，每个动作都可以上移、下移、删除。

## 导出

通过顶栏「文件」菜单访问：

| 格式 | 说明 |
|------|------|
| 导出元素（HTML 片段） | 当前页面的纯 HTML 片段，不含样式与脚本 |
| 导出完整网页 | 单文件 HTML，包含所有页面、主题、样式与脚本 |
| 导出 ZIP | 多页面结构，媒体文件打包到 `pages/images/` |
| 导出 PDF | 打开打印窗口，在打印机中选择「另存为 PDF」 |
| 导出 Markdown | 结构化的 Markdown 文本，便于迁移到其他工具 |
| 导出 JSON | 完整的文档数据，可用于备份或迁移 |

导入功能接受本工具导出的 JSON 文件，会替换当前画布内容。导入前建议先保存。

## 快捷键

| 快捷键 | 操作 |
|--------|------|
| `Ctrl` + `Z` | 撤销 |
| `Ctrl` + `Y` 或 `Ctrl` + `Shift` + `Z` | 重做 |
| `Ctrl` + `S` | 保存到浏览器本地 |
| `Ctrl` + `P` | 预览 |
| `Ctrl` + `D` | 复制选中的块 |
| `Delete` | 删除选中的块 |
| `Ctrl` + `K` | 在可编辑文本中插入超链接 |
| `Ctrl` + `Shift` + `T` | 打开主题面板 |
| `Ctrl` + `Shift` + `F` 或 `F11` | 全屏切换 |
| `↑` / `↓` | 移动选中的块 |
| `Esc` | 取消选中或关闭弹窗 |
| `?` | 显示帮助 |

多选：按住 `Ctrl`（macOS 用 `Cmd`）点击块可加入选择集，此时删除、复制等操作会作用于全部选中块。

## 存储与隐私

- 编辑内容自动保存到浏览器的 `localStorage`，键名为 `docbuilder_v20`
- 面板宽度等偏好保存在 `docbuilder_panel_w`
- 图片、视频等媒体以 Data URL 形式保存在本地；导出 ZIP 时会打包为独立文件
- 所有数据仅存于本机浏览器，不会上传到任何服务器
- 通过「文件 → 清除本地存储」可清除自动保存的内容

## 浏览器支持

依赖现代浏览器的以下特性：

- CSS 自定义属性与 `color-mix()`
- `IntersectionObserver`
- `ResizeObserver`（可选，部分地方使用）
- `execCommand`（用于富文本编辑，已被标记为废弃但主流浏览器仍支持）
- `FileReader`、`Blob`、`URL.createObjectURL`

推荐 Chrome 100+、Edge 100+、Firefox 100+、Safari 15.4+。

## 依赖

所有依赖通过 CDN 加载：

- Font Awesome 6.5.2（图标）
- highlight.js 11.9.0（代码高亮）
- KaTeX 0.16.11（数学公式）
- marked 14.1.3（Markdown 渲染）
- JSZip 3.10.1（ZIP 导出）

若某项依赖加载失败，启动页会明确提示，相关功能不可用但不影响其他功能的使用。

## 已知限制

- 富文本编辑依赖浏览器的 `execCommand`，在极端复杂的选区操作下可能表现不一致
- 代码块内粘贴时会统一转换为纯文本，不保留源格式
- 页面嵌入仅展开一层，避免循环引用
- PDF 导出依赖浏览器的打印功能，不同浏览器的分页效果会有差异
- 触发器仅作用于当前页面内的块，不跨页面执行

## 许可

本工具为单文件应用，可自由使用、修改与分发。
