    欢迎使用文档制作工具

    选择一种模板快速开始，或点右上角「以空白开始」从零创作。

    触发器点击时按列表顺序依次执行动作，支持嵌套的循环与条件判断。

    触发器动作

    每个触发器可配置一串动作，点击时按顺序执行。新增动作类型：

    • 循环执行：可指定次数，循环体内可再嵌套动作
    • 条件判断：根据元素是否可见 / 文字内容 / 类名来走不同分支
    • 移动目标位置：按 dx/dy 像素偏移，可设置动画时长
    • 改变目标颜色：修改文字色 / 背景色 / 边框色

    页面层级

    在左侧页面列表中拖动页面：放在另一页面的上/下沿为同级排序，放在中段则成为其子页面。

    主题与外观
    显示模式

    每套风格都有独立的圆角、阴影、边框、字体、背景与配色。深色模式会影响整个编辑器界面与导出网页。

    自定义 CSS 会追加在主题之后，写入预览与导出的文档中。 推荐通过覆盖 --doc-* 变量换色（见「CSS 变量文档」），或用选择器对具体组件做深度定制。

    自定义 CSS 只作用于文档，不影响编辑器界面
